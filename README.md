# mentis · тренажёр устного счёта

Тренажёр устного счёта в теме **обсерватории**: навыки — созвездия, рекорды и звания — латунь, тёмная тема — ночное небо, светлая — бумажный звёздный атлас. Самодостаточный [`index.html`](index.html): встроенные CSS и JS, работает полностью офлайн (по двойному клику, `file://`), прогресс — в `localStorage`.

**Онлайн:** <https://soloveyska1.github.io/mentis-trainer/>

## Структура приложения

Пять вкладок (на телефоне — нижний таб-бар):

- **Сегодня** — вахта: сеанс дня, контрольная (раз в неделю), быстрый старт, цель дня, что готово к повтору.
- **Тренировка** — свободный счёт: Адаптив·поток / Спринт·Zetamac / Выживание + **Рейтинговый забег** (лига).
- **Упражнения** — каталог по смыслу: понимание приёмов · приёмы и дриллы · повторение · числовое чутьё · внимание и память.
- **Дуэль** — вдвоём: рядом на одной клавиатуре или онлайн по коду комнаты.
- **Прогресс** — сводка, операции, лига, созвездие мастерства, память на факты, калибровка, постоянство.

## Что внутри

- **Адаптивная сложность** держит ~85 % успеха; разбор ошибки — интерактивный, по шагам приёма (20 приёмов, решатель проверен брутфорсом).
- **Понимание, не зубрёжка**: «Эквивалентности» (тождества, на которых стоят приёмы — верно/ловушка), «Найди ошибку» (подпорченный шаг решения), «Выбор приёма» (узнай форму примера до счёта).
- **Последствия**: рейтинговый забег — Elo-подобный рейтинг растёт и падает по результату, звания от Наблюдателя до Магистра счёта; **Гонка с тенью** — в каждом таймed-забеге гонишься со своим лучшим прогоном этой конфигурации.
- **Память на факты** — интервальные повторения (FSRS) с неявными повторами и критерием беглости по времени реакции; «Контрольная» (кумулятивный экзамен); «Перемешка» (интерливинг).
- **Метапознание** — уверенность и гиперкоррекция (уверенные ошибки возвращаются на пересдачу), калибровка самооценки, карта мастерства.
- **Дуэли** — локальная «гонка-зеркало» (зеркальные зоны клавиатуры, без помех) и онлайн на двух телефонах: встроенный MQTT-клиент (без CDN), несколько публичных брокеров одновременно, QoS 1 — соединение выживает при блокировке части брокеров.

## Как открыть

Открой ссылку выше или скачай репозиторий и открой `index.html` в браузере.

### Установка на телефон (iPhone)

Открой ссылку в Safari → «Поделиться» → «На экран „Домой“». Приложение встанет с фирменной иконкой, запускается на весь экран и **работает офлайн** (service worker кэширует оболочку).

## Структура репозитория

- `index.html` — всё приложение целиком.
- `sw.js` — service worker (офлайн-кэш оболочки).
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `favicon-32.png` — PWA-ассеты.
