# mentis · тренажёр устного счёта

Премиальный тренажёр устного счёта. Самодостаточный [`index.html`](index.html): встроенные CSS и JS, работает полностью офлайн (по двойному клику, `file://`), прогресс хранится в `localStorage`.

**Онлайн:** <https://soloveyska1.github.io/mentis-trainer/>

## Возможности

- **Арифметика** — адаптивная сложность держит зону ~85 % успеха (Адаптив·поток, Спринт·Zetamac, Выживание), дашборд с динамикой, теплокартой постоянства и рекордами.
- **Приёмы счёта** — правило → дрилл → интерактивный разбор приёма при ошибке (×11, квадрат на 5, округление, крест-накрест и др.); «Перемешка» (интерливинг приёмов).
- **Память и внимание** — N-back, Числовой ряд, Числовой Струп, Таблица Шульте, Флеш-анзан.
- **Числовое чутьё** — проценты и прикидка, степени и корни, числовая прямая, прикидка перед ответом.
- **Память на факты** — интервальные повторения (FSRS-модель) с неявными повторами; «Контрольная» (кумулятивный экзамен); критерий беглости по времени реакции.
- **Метапознание** — уверенность + гиперкоррекция, калибровка самооценки, карта мастерства, карта таблицы умножения.
- **Дуэли вдвоём** — «Гонка-зеркало» на одной клавиатуре и «Онлайн» на двух телефонах по коду комнаты.

## Как открыть

Открой ссылку выше или скачай репозиторий и открой `index.html` в браузере.

### Установка на телефон (iPhone)

Открой ссылку в Safari → «Поделиться» → «На экран „Домой“». Приложение встанет с фирменной иконкой и будет запускаться на весь экран, как нативное.

## Структура

- `index.html` — приложение целиком (живой артефакт).
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `favicon-32.png` — PWA-ассеты (установка на рабочий стол).
- `coach.js`, `mastery.js`, `_session_component.js`, `*.css` — исходники отдельных модулей (для удобства правок; в `index.html` встроены).
