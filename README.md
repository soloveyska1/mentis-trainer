# mentis · тренажёр устного счёта

Премиальный офлайн-тренажёр устного счёта. Один самодостаточный файл — [`index.html`](index.html): встроенные CSS и JS, ноль внешних запросов, работает по двойному клику (`file://`), полностью офлайн. Прогресс хранится локально в `localStorage`.

## Возможности

- **Арифметика** — адаптивная сложность держит зону ~85 % успеха (Адаптив·поток и Спринт·Zetamac), дашборд с динамикой, теплокартой постоянства и рекордами.
- **Приёмы счёта** — правило → дрилл → интерактивный разбор приёма при ошибке (×11, квадрат на 5, округление, крест-накрест и др.).
- **Память и внимание** — N-back, Числовой ряд, Числовой Струп, Таблица Шульте, Флеш-анзан.
- **Числовое чутьё** — проценты и прикидка, степени и корни, проверка девяткой.
- **Обучение на ошибках** — спейсинг-повтор (Лейтнер/SM-2), карта мастерства, карта таблицы умножения.

## Как открыть

Скачай репозиторий и открой `index.html` в браузере — больше ничего не нужно.

## Структура

- `index.html` — приложение целиком (живой артефакт).
- `coach.js`, `mastery.js`, `_session_component.js`, `*.css` — исходники отдельных модулей (для удобства правок; в `index.html` они встроены).
